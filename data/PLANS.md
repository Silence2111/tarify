# Тарифы — как завести и обновлять

Провайдер появляется в поиске, только когда у него есть **и покрытие** по адресу
(см. [COVERAGE.md](COVERAGE.md)), **и хотя бы один активный тариф**. Тарифы загружаются
CSV-файлом: `/admin/plans` → «Импорт тарифов из CSV». Там же видно, какие провайдеры
сейчас не попадают в поиск и почему.

## Формат CSV

Шаблон: [plans-template.csv](plans-template.csv) — цифры в нём примерные (как в демо-данных).
Одна строка — один тариф. Разделитель — запятая или точка с запятой (так сохраняет
русский Excel), оба варианта понимаются.

| Колонка | Обяз. | Что это |
|---|---|---|
| `provider` | да | Слаг провайдера латиницей (`rostelecom`) — тот же, что в CSV покрытия |
| `plan` | да | Название тарифа. По нему тариф узнаётся при следующей загрузке |
| `price` | да | Цена в месяц, ₽, целое число (`1 200` и `1200 ₽` тоже можно) |
| `price_first` | нет | Цена первого месяца по акции, ₽ (`0` — бесплатно) |
| `speed` | нет | Скорость, Мбит/с |
| `tv` | нет | Число ТВ-каналов или `да`; пусто или `нет` — без ТВ |
| `mobile` | нет | ГБ мобильного интернета или `да`; пусто или `нет` — без мобильной связи |
| `type` | нет | `INTERNET` (по умолчанию), `TV`, `MOBILE` или `BUNDLE` |
| `description` | нет | Описание для карточки тарифа |
| `options` | нет | Опции через `;`: `Wi-Fi роутер: в аренду 99 ₽/мес; Статический IP: 150 ₽/мес` |
| `provider_name` | нет | Отображаемое имя провайдера. Новый провайдер создастся с ним, у существующего — обновится |
| `payout` | нет | Ставка CPA за подтверждённое подключение, ₽. Если заполнена — становится ставкой провайдера: по ней админка считает выручку |

## Как работает загрузка

- **Файл — актуальный прайс провайдера.** Тарифы из файла создаются или обновляются
  (по названию). Тарифы этого провайдера, которых в файле нет, **скрываются** с сайта.
  Их не удаляем — на них ссылаются заявки; вернёте строку в файл — тариф снова появится.
- **Провайдеров, которых в файле нет, загрузка не трогает** — прайсы можно грузить по одному.
- **Поля тарифа — ровно как в файле:** пустая ячейка `description` уберёт описание,
  пустая `options` — опции.
- **Пустые `provider_name` и `payout` ничего не меняют** — чтобы пустая ячейка не обнулила ставку.
- **Ошибка хоть в одной строке — не загружается ничего.** Админка покажет строки с ошибками;
  исправьте и загрузите снова. Проверяется и то, что тариф не повторяется, а у одного
  провайдера в разных строках не стоят разные `payout` или `provider_name`.

## Демо → реальные тарифы

1. Для каждого провайдера, с которым есть оффер в CPA-сети, соберите прайс с его сайта
   и загрузите — демо-тарифы этого провайдера скроются сами.
2. Ставку `payout` берите из карточки оффера в CPA-сети.
3. Демо-провайдеры без реальных данных пропадут из поиска, когда будут удалены демо-города
   (у них не останется покрытия) — см. [COVERAGE.md](COVERAGE.md).
