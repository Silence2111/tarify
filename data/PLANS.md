# Тарифы — как завести и обновлять

Все тарифы сайта — домашний интернет, мобильная связь, расчётные счета для бизнеса —
загружаются CSV-файлом: `/admin/plans` → «Импорт тарифов из CSV». Там же видно, где каждый
провайдер показывается на сайте и почему его может не быть.

Где тариф появляется, решает колонка `type`:

| `type` | Где на сайте | Что нужно, чтобы тариф было видно |
|---|---|---|
| `INTERNET`, `TV`, `BUNDLE` | поиск по адресу, страницы городов и улиц | покрытие дома ([COVERAGE.md](COVERAGE.md)) + активный тариф |
| `MOBILE` | `/mobile`, `/mobile/<оператор>`, блок на страницах городов | активный тариф; цены — по регионам |
| `BUSINESS_ACCOUNT` | `/business`, расчётные счета | активный тариф |

Шаблоны (цифры в них примерные, как в демо-данных):
[plans-template.csv](plans-template.csv) — домашний интернет,
[mobile-template.csv](mobile-template.csv) — мобильная связь,
[business-accounts-template.csv](business-accounts-template.csv) — счета для бизнеса.
Одна строка — один тариф. Разделитель — запятая или точка с запятой (так сохраняет
русский Excel), оба варианта понимаются.

## Колонки

| Колонка | Обяз. | Что это |
|---|---|---|
| `provider` | да | Слаг провайдера латиницей (`rostelecom`, `mts`, `tbank`) — тот же, что в CSV покрытия |
| `plan` | да | Название тарифа. По нему тариф узнаётся при следующей загрузке |
| `price` | да | Цена в месяц, ₽, целое число (`1 200` и `1200 ₽` тоже можно; `0` — бесплатно) |
| `type` | нет | `INTERNET` (по умолчанию), `TV`, `BUNDLE`, `MOBILE` или `BUSINESS_ACCOUNT` |
| `region` | нет | Регион цены — как у городов в базе (`Москва`, `Татарстан`). Пусто — цена одна по всей России |
| `price_first` | нет | Цена первого месяца по акции, ₽ (`0` — бесплатно) |
| `speed` | нет | Скорость домашнего интернета, Мбит/с |
| `tv` | нет | Число ТВ-каналов или `да`; пусто или `нет` — без ТВ |
| `gb` (или `mobile`) | нет | Гигабайты мобильного интернета, `безлимит` или `да` |
| `minutes` | нет | Минуты в месяц или `безлимит` |
| `sms` | нет | SMS в месяц или `безлимит` |
| `esim` | нет | `да`, если можно подключить eSIM |
| `url` | нет | Партнёрская ссылка из кабинета CPA-сети (только `http(s)`). С ней кнопка «Оформить» ведёт на сайт оператора или банка; без неё — заявка с обзвоном. Вставьте `{subid}` туда, куда сеть просит передавать метку (например `&subid={subid}`): сайт подставит номер перехода, а постбэк сети вернёт его со статусом — это видно в `/admin/clicks` |
| `erid` | нет | Токен маркировки рекламы, если сеть его выдала. Показывается под кнопкой: «Реклама · провайдер · erid» |
| `description` | нет | Описание для карточки тарифа |
| `options` | нет | Опции через `;`: `Wi-Fi роутер: в аренду 99 ₽/мес; Статический IP: 150 ₽/мес` |
| `provider_name` | нет | Отображаемое имя провайдера. Новый провайдер создастся с ним, у существующего — обновится |
| `payout` | нет | Ставка CPA за подтверждённое подключение, ₽. Если заполнена — становится ставкой провайдера: по ней админка считает выручку с заявок |

## Как работает загрузка

- **Файл — актуальный прайс пары «провайдер + регион».** Тарифы из файла создаются или
  обновляются (по названию). Тарифы этой пары, которых в файле нет, **скрываются** с сайта.
  Их не удаляем — на них ссылаются заявки; вернёте строку в файл — тариф снова появится.
  Прайс МТС для Москвы не трогает тарифы МТС в Татарстане — регионы можно грузить по одному.
- **Провайдеров и регионов, которых в файле нет, загрузка не трогает.**
- **Поля тарифа — ровно как в файле:** пустая ячейка `description` уберёт описание,
  пустая `options` — опции, пустая `url` — ссылку.
- **Пустые `provider_name` и `payout` ничего не меняют** — чтобы пустая ячейка не обнулила ставку.
  У МТС и Билайна одна ставка и для домашнего интернета, и для SIM: в прайсе мобильной связи
  `payout` лучше оставлять пустым. Заработок по партнёрским ссылкам считает CPA-сеть, а не
  админка — выручка в `/admin/leads` учитывает только заявки.
- **История цен пишется сама.** Если у тарифа изменилась цена, в ленту `/izmeneniya-cen`
  попадёт «подорожал» или «подешевел» с датой и процентом, а на карточке тарифа 60 дней будет
  пометка «подорожал на 50 ₽ · 24 сент.». Новые и снятые тарифы тоже попадают в ленту. Первая
  загрузка прайса пары «провайдер + регион» в ленту не попадает — это не новость. Тариф узнаётся
  по названию: переименованный тариф в ленте будет снятым и новым. Если настроен Telegram-канал
  (`TELEGRAM_CHANNEL_ID`, см. DEPLOY.md), изменения сразу уходят туда постом.
- **Ошибка хоть в одной строке — не загружается ничего.** Админка покажет строки с ошибками;
  исправьте и загрузите снова. Проверяется и то, что тариф не повторяется в одном регионе,
  а у одного провайдера в разных строках не стоят разные `payout` или `provider_name`.

## Демо → реальные тарифы

1. Для каждого провайдера, с которым есть оффер в CPA-сети, соберите прайс с его сайта
   и загрузите — демо-тарифы этого провайдера (в этом регионе) скроются сами.
2. Ставку `payout` и партнёрские ссылки `url` берите из карточек офферов в CPA-сети;
   `erid` — там же, если сеть требует маркировку.
3. Мобильные тарифы операторов стоят по-разному в каждом регионе — грузите цены тех регионов,
   где есть города на сайте. Каждый регион с ценами получает свои страницы: `/mobile/<регион>`,
   `/mobile/<оператор>/<регион>` и подборки региона — они сразу попадают в `sitemap.xml`. Виртуальные операторы с единой ценой (Т-Мобайл, СберМобайл) —
   с пустым `region`.
4. Демо-провайдеры без реальных данных пропадут из поиска по адресу, когда будут удалены
   демо-города (у них не останется покрытия) — см. [COVERAGE.md](COVERAGE.md).
