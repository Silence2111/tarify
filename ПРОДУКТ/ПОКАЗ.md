# Тарифы — как показывать

## Запуск

```bash
cd ~/Projects/тарифы && npm run demo
```

Открыть http://127.0.0.1:3050. Скрипт сам поднимает свой Postgres без
установки: embedded-postgres на порту `PGPORT_LOCAL`, по умолчанию 5435,
данные лежат в `.pgdata-demo`. Потом заливает демо-данные, собирает сайт
и запускает его. Базу из `.env` он не трогает: там 5433, а на этом порту
сейчас работает Postgres ТехноХода. Если порт занят, скрипт так и скажет
и подскажет, как запустить на другом.

Админка: `/admin`, пароль `demo-admin`.

**Живой прод есть:** tarify.rumedia-cdn.com (Vercel, база на Neon,
выкатывается из `main`). Не выкатывал: по брифу push в `main` запрещён,
а для этого проекта push в `main` и есть выкатка. На проде сейчас старая
версия. Там реальные бренды (Ростелеком, МТС и другие) с выдуманными
тарифами и три города.

## Сценарий в три шага

1. **Главная.** Что это, для кого, «бесплатно», один главный призыв. Под
   поиском есть кнопки «Демо-адреса»: одно нажатие открывает выдачу.
   Строка «Сейчас в базе: Казань — 18 домов… Это демо-данные» прямо
   говорит о масштабе.
2. **Выдача по дому.** Фильтры по цене, скорости и ТВ, технология подключения
   по-русски. «Подключить» → имя, телефон, согласие → «Заявка принята.
   Это демо: звонка не будет». Заявку видно в `/admin/leads`.
3. **Адреса нет.** Например, «Лесная, 1»: честно пишем «нет в базе» и
   предлагаем форму ручного подбора. Дом не найден, но улица есть
   («Баумана, 99»): показываем провайдеров улицы и предупреждаем, что
   в конкретный дом может заходить не каждый.

## Чего не обещать

- **Покрытие.** У лидера рынка 7 млн адресов, у нас 18 демо-домов
  в одном городе. Провайдеры «А–Д (демо)» вымышленные, цены тоже.
- **Звонок и подключение.** Колл-центра и договоров с CPA-сетями нет.
- **Реквизиты.** В политике и контактах стоят пометки «заполнить».
